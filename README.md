**Public timestamp vault for original cyberpunk fiction.**

This repository is the official proof-of-creation archive for the EchoFang YouTube series. Every story, case file, and script fragment is committed here *before* the video goes live. GitHub's commit history is the timestamp.

### What this is

- `index.md` = the public site at **rob42261.github.io/Cyberpunk/**
- `/cases/` = individual case files (coming soon)

### How proof works

1. Story written
2. Markdown file committed to `main`
3. GitHub records an immutable date/time + hash
4. YouTube video published after that commit

If anyone questions origin, the commit history is the receipt.
